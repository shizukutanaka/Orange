# ADR 002 — DomesticSpoofDetector: only 020 prefix is reserved, not all 02x

**Date:** 2025-05  
**Status:** Accepted

## Context

An initial implementation rejected all numbers with `second_digit == '2'`,
intending to catch the MIC-reserved 020 (net services) prefix. This incorrectly
blocked 022 (仙台), 023 (山形), 024 (福島), 025 (新潟), 026 (長野), 027 (前橋),
028 (宇都宮), 029 (水戸) — 8 geographic area codes covering Tohoku and inland
Kanto. Notably, 8 of the 47 prefectural police HQ numbers in the bundled
directory were being silenced before the police-HQ layer could fire.

## Decision

Change the check from `secondDigit == '2'` to `domestic.startsWith("020")`.

## Consequences

- Legitimate calls from Tohoku/inland Kanto ring correctly.
- `020-XXXX` (MIC net services, unallocated) still blocked.
- The police HQ directory functions correctly for all 47 entries.
