Orange — Privacy Policy

Last updated: May 2026

What Orange collects

Nothing. Orange does not collect, transmit, store, or share any personal data with anyone, including the developer.

Permissions

READ_CALL_LOG — Required by Android's CallScreeningService contract so Orange can inspect the phone number of incoming calls and decide whether to silence them. The call log is read on-device only and is never transmitted.

POST_NOTIFICATIONS — During the first seven days after install, Orange shows a silent notification for each blocked call so the user can restore false positives. After seven days, no notifications are shown.

RECEIVE_BOOT_COMPLETED — Allows Orange to check whether its screening role is still active after a device reboot.

Permissions deliberately not requested

INTERNET — Orange has no server. It makes no HTTP requests, sends no telemetry, uploads no crash reports, and contacts no analytics service. The entire product runs offline after installation.

READ_CONTACTS — Orange does not access the user's address book. Caller identification uses a bundled offline business directory, not the user's contacts.

Data storage

Orange stores a small amount of data on the device in the app's private SharedPreferences. This includes: a set of phone numbers the user has dialed (so their callbacks ring through), a set of phone numbers the user has blocked, and a cumulative block count. This data is excluded from Android Auto Backup and device-to-device migration. Uninstalling Orange permanently deletes all stored data.

Third-party services

None. Orange contains no third-party SDKs, no advertising frameworks, no analytics libraries, and no crash-reporting tools.

Children's privacy

Orange does not knowingly collect any information from children under the age of 13. The app does not collect information from anyone.

Changes to this policy

If Orange ever adds a feature that changes this privacy posture, this policy will be updated before the feature ships. The policy is versioned in the same Git repository as the source code; the commit history is the audit trail.

Contact

Questions about this policy can be directed to the project's GitHub Issues page.
