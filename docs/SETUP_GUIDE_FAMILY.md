# Orange 家族向けセットアップガイド

このガイドは、**ご高齢の家族のスマホに Orange を設定してあげる方**のためのものです。
所要時間は約5分。設定が終われば、その後の操作はほぼ不要です。

## Orange とは

迷惑電話・特殊詐欺の電話を、着信音が鳴る前に自動で止めるアプリです。

- **アカウント登録なし** — メールアドレスも電話番号の登録も不要
- **通信なし** — インターネット権限を持たないため、データが外部に送られることは構造上ありえません
- **連絡先を読まない** — 電話帳へのアクセス権限を要求しません
- **無料・広告なし** — 課金要素はありません

## 設定手順

### 1. インストールして開く

アプリを開くと、オレンジ色の画面に白い丸が1つだけ表示されます。

### 2. 白い丸(「守る」)をタップ

Android が「Orange を発着信スクリーニングアプリに設定しますか?」と確認して
くるので、**「Orange を設定」(許可)** を選びます。これだけで保護が始まります。

### 3. 家族の番号を登録(推奨)

初回設定の直後に「家族の連絡先」画面が開きます。
**あなた(見守る側)の携帯番号** をスロット1に入力して保存してください。

これを設定しておくと:
- 不審な電話の警告が出たとき、通知に **「家族に連絡」ボタン** が表示され、
  ワンタップであなたに電話できます
- クイック設定(画面上から下にスワイプ)に「家族に連絡」タイルを追加すれば、
  いつでもワンタップであなたに発信できます

### 4. ウィジェットを置く(任意)

ホーム画面を長押し → ウィジェット → Orange を追加すると、
「今までに止めた件数」が表示されます。タップするとブロック履歴が見られます。

## 設定後に知っておくこと

### 病院などの大事な電話が止められてしまったら

- 最初の1週間は、ブロックのたびに通知が出ます。通知の **「解除」** を押せば
  その番号は次回から鳴ります
- それ以降も、**ウィジェットをタップ → ブロック履歴 → 「許可」** でいつでも
  解除できます

### 一時的に全部の電話を受けたいとき

クイック設定の **Orange タイル** をタップすると、1時間だけすべての着信が
鳴るようになります(非通知も含む)。病院からの折り返しを待つときなどに。

### 絶対に止まらない電話

110・119・118 などの緊急番号は、どんな設定でも必ず鳴ります。

### Orange が効かなくなったように見えたら

ウィジェットの数字が「·」になっている場合、Android の設定変更や OS 更新で
スクリーニング権限が外れています。**ウィジェットをタップ** すれば再設定画面が
開きます。

## 注意 — Orange が防げないもの

Orange は万能ではありません。実在する正規の国内番号からの詐欺電話
(例: レンタル携帯を使った詐欺)は通常どおり鳴ります。
「電話でお金の話が出たら、一度切って家族か #9110(警察相談) に相談」という
基本は、アプリがあっても変わらないことをご家族に伝えてください。
